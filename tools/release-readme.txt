hv86 - гипервизор, в котором ВМ исполняет v86 (x86 -> WebAssembly)
=================================================================

Что внутри
  hv86.exe    интерфейс + служба + движок одним файлом (.NET 9, self-contained)
  engine\     headless-движок (v86 в Node): ВМ без графики, живёт в сессии службы
  README.txt  этот файл

Требуется
  Windows 10/11 x64 и Microsoft Edge WebView2 Runtime (есть в Windows 11 по
  умолчанию; если нет - приложение скажет, откуда скачать)

Быстрый старт: без установки службы (портативный режим)
  1. Запустите hv86.exe. Windows спросит разрешение администратора - оно нужно,
     чтобы запускать процессы ВМ и писать в %ProgramData%\hv86.
  2. "Новая ВМ..." -> пресет FreeDOS -> Создать -> Подключиться.
  В этом режиме движок работает внутри приложения. Окно можно закрыть -
  приложение останется в трее, ВМ продолжат работать; выход из трея ("Exit")
  останавливает их со штатным сохранением дисков. Чтобы ВМ работали без
  интерфейса и переживали выход из системы - поставьте службу (ниже).

Работа в фоне: служба Windows
  hv86.exe --service install      установить (нужен администратор)
  hv86.exe --service start        запустить
  hv86.exe --service stop         остановить
  hv86.exe --service uninstall    удалить
  Служба поднимается вместе с Windows, ВМ продолжают работать после выхода из
  интерфейса и переживают смену пользователя. Интерфейс подключается к ней сам -
  ставить службу задним числом можно в любой момент (кнопка в меню "...").

Где лежат данные
  %ProgramData%\hv86\            корень (переменная HV86_ROOT переопределяет его)
  %ProgramData%\hv86\logs\       логи (hv86-ui-*.log, hv86-vm-<id>-*.log)
  %ProgramData%\hv86\vms\<id>\   описание ВМ, диски, снапшоты, чекпоинты

headless-движок (engine\)
  Нужен только для ВМ с engine=headless: они живут в сессии службы, показывают
  VGA-текст и не умирают при выходе из системы. Требует Node.js 20+ в PATH
  (или engine\node\node.exe).

Управление из консоли
  hv86.exe --cli list
  hv86.exe --cli create --name dev --preset tinycore --memory 256 --disk 256
  hv86.exe --cli start dev
  hv86.exe --cli type dev "dir" --enter
  hv86.exe --cli snapshot dev before-update
  hv86.exe --cli help
