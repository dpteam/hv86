# Экран консоли: текстовый слой, масштаб, мышь

Короткая памятка о том, как устроен экран и на чём уже спотыкались.

## Текстовый слой

v86 рисует текстовый режим как `<div>` внутри `#screen_container`, по одному
`<div>` на строку, а внутри — `<span>` с цветами. Строк столько, сколько
объявил гость (обычно 25). Шрифт, размер и межстрочный интервал задаются CSS
на этом слое: гость про них не знает.

**Грабли (реальный баг).** В CSS консоли стояло `.screen { line-height: 0 }` —
это было нужно для canvas, чтобы не было зазора снизу. Но свойство
наследуется, а `applyTextFont` при пустой настройке шрифта **очищал**
inline-`line-height`, и слой получал `0`. Все 25 строк рисовались друг на друге
— на экране была одна полоса текста.

Как теперь:

- в CSS `line-height: 0` нет, для canvas достаточно `display: block`;
- `applyTextFont` ставит `font-size` и `line-height` **всегда**, даже когда
  шрифт не выбран (по умолчанию 14 px);
- `--itest` проверяет, что в слое ≥20 строк и высота слоя > 200 px, — регрессия
  не пройдёт молча.

## Масштаб

Масштабируем через CSS `zoom` на контейнере, а не `screen_set_scale` v86: тот
ставит `transform`, который не меняет layout, и центрирование врёт. Собственный
масштаб v86 снимается в `normalizeScreen()` на каждом `screen-set-size`.

## Мышь

- Захват (pointer lock) — по кнопке в панели **и** по клику на экран
  (настройка `capture_on_click`, по умолчанию включена).
- Захват по клику работает только если гостевой драйвер включил мышь
  (`mouse-enable` от v86). Если гость мышь не включил, в строке состояния
  честно написано: «гость не включил мышь: в его ОС нет драйвера мыши».
  Иначе захват выглядел бы как «мышь пропала».
- Выход настраивается в настройках хоста: F8+F12 (по умолчанию, как в 86box),
  средняя кнопка, Esc, Ctrl+Alt.

## Диагностика

`hv86 --cli screen <vm>` для web-движка печатает не текст (его рисует WebView2),
а состояние слоя: число строк, высоту слоя и контейнера, шрифт, межстрочный
интервал, масштаб. Этого хватает, чтобы отличить «гость ничего не вывел» от
«вывел, но слой схлопнулся».
