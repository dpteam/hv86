# Откуда берём образы

Каталоги пресетов — это **метаданные**, а не файлы: URL, медиа, память, размер,
при наличии — SHA-256. Образ качается при создании ВМ. Поэтому «источник» —
это просто список прямых ссылок, которые надо проверить.

## Что уже подключено

| каталог | файл | сколько | хэши |
|---|---|---|---|
| свои, проверенные | `assets/presets.json` | 6 | обязательны, вписаны руками |
| copy.sh/v86 | `assets/presets-copy.json` | 118 | закрепляются при первой загрузке |
| old-dos.ru | `assets/presets-olddos.json` | 15 (6 одиночных + 9 комплектов дискет) | закрепляются при первой загрузке |

## Как добавить новый образ (чек-лист)

1. **Прямая ссылка на один файл.** Не страница с кнопкой, не торрент, не
   `?download=1` с сессией. Проверить: `Invoke-WebRequest -Method Head` должен
   вернуть 200 и `Content-Length`.
2. **Образ или комплект дискет внутри.** Если это ZIP — внутри либо ровно один
   `.img/.iso/.ima/.flp`, либо несколько, но все дискеты (комплект: `ImagePack`
   раскладывает их по порядку, консоль умеет листать «◀ 2/5 ▶»). RAR/7z не
   поддерживаются; смешанный набор (дискета + CD) отвергается.
3. **Сигнатура.** ISO — `CD001` на смещении 0x8001; флоппи — размер из
   стандартных (360K/720K/1.2M/1.44M/2.88M); винчестер — что-то осмысленное
   ≥ 2 МБ.
4. **Хэш.** Для своего пресета — посчитать и вписать в JSON
   (`Get-FileHash -Algorithm SHA256`). Для чужих каталогов — оставить пустым:
   закрепится при первой загрузке.
5. **Boot-тест.** Создать ВМ из пресета в headless-движке, стартовать, прочитать
   экран (`hv86 --cli screen`). «Один образ» ≠ «загружается»: установочная
   дискетка Windows 1.0 — тоже один образ, но не загрузочная.
   Скрипт: `tools/old-dos-boot.ps1 -Presets <id,...>`. Для сырых кандидатов old-dos
   (ещё не пресетов) — `tools/old-dos-smoke.mjs <scan.json> <out.json>`: он берёт
   первую дискету архива и гоняет `hv86 --smoke`.

## Проверенные источники, где лежат одиночные образы

- **ELKS** (Linux для 8086) — GitHub releases:
  `https://github.com/ghaerr/elks/releases/download/v0.9.2/fd1440.img`
  (1.44M флоппи, 1 474 560 байт, sha256 `bb4e3ac2…`). Уже в своих пресетах.
  Там же есть `fd1200*.img`, `fd2880*.img`, варианты fat/minix.
- **copy.sh/v86** — весь демо-стенд; список вытаскивается из бандла
  (`tools/copy-sh-list.mjs`), ничего не хардкодим.
- **old-dos.ru** — пригодное лежит в типах «Образ CD» и «Идеальная копия
  оригинального носителя», плюс комплекты дискет (MS-DOS/PC DOS, Windows 1.x–3.x)
  — подробности и правила отбора в `docs/research/old-dos.md`.
- **FreeDOS** — `https://www.ibiblio.org/pub/micro/pc-stuff/freedos/files/distributions/1.3/official/`
  (`FD13-LiveCD.zip` 393 МБ, `FD13-FloppyEdition.zip` 21 МБ). LiveCD подойдёт как
  ISO; FloppyEdition — набор образов, его можно взять только вместе со сменой
  дискет и после boot-проверки.

## Где искать дальше (не подключено)

- **archive.org**: у item'ов прямые ссылки вида
  `https://archive.org/download/<item>/<file>` и поддержка Range; но качество
  сборок надо проверять руками.
- **winworldpc.com**: каталог хороший, скачивание — через сессию, прямыми
  ссылками не отдаётся.
- **vetusware / oscollect**: мелкие архивы, много дублей.
- **проекты напрямую**: MenuetOS, Visopsys, FreeGEM, Haiku, ReactOS, Minix —
  у каждого свои страницы загрузок, ссылки нестабильны, проверять HEAD'ом.

## Почему не тащим файлы в репозиторий

GitHub не примет файл больше 100 МБ, а тут от 512 байт до гигабайта; плюс
образы Windows — чужие лицензионные сборки. Поэтому в git едут только JSON'ы с
ссылками, а «поставка» — это exe + движок.
